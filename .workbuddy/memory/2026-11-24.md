## 六个页面接入侧边栏

- `src/pages/` 之前只有空目录：`mainwindow/` 下六个 0 字节文件（home/artist/zhuanji/myfavorite/mystars + lib.rs），
  `settings/` 为空目录。缺「音乐库」页 → 新建 `library.rs`。
- 模块树（bin crate 里 `mainwindow/lib.rs` 当模块根，需要 `#[path]`）：
  - `src/pages/mod.rs`：`#[path = "mainwindow/lib.rs"] pub mod mainwindow;`
  - `src/pages/mainwindow/lib.rs`：`pub mod home; ...` + 共享占位组件 `pub fn placeholder(icon,title,hint,cx)`（图标胶囊 + 标题 + 说明，居中）。
  - 每个页面文件暴露 `pub fn view(cx: &mut App) -> AnyElement`。
- `main.rs`：加 `mod pages;`；`Destination::page(self, cx)` 用 match 分发到六个页面，
  `Settings` 复用 `placeholder(LucideIcon::Settings, ...)`；`render` 里原来的居中占位块换成
  `div().flex_1().min_w_0().h_full().child(self.active.page(cx))`。
- 验证：`cargo build` 通过、50 项测试全过、启动无 panic。
- 页面目前都是占位；接真实内容时替换各自 `view` 的函数体即可。
